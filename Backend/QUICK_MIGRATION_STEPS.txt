================================================================================
WHAT THIS MIGRATION CREATES
================================================================================

✓ cms_settings
  - Main configuration store for landing page customization
  - Contains settings_data JSONB column (colors, typography, layout, etc)
  - One record per tenant

✓ cms_settings_versions
  - Version history for rollback capability
  - Tracks all changes to settings

✓ cms_audit_log  
  - Audit trail for compliance
  - Logs all admin actions

✓ theme_presets
  - Pre-configured theme templates (6 defaults):
    1. Modern Minimal
    2. Corporate
    3. Creative
    4. Bold Tech
    5. Startup
    6. Luxury
